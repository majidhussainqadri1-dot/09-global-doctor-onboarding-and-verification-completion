Completes the platform workflow for worldwide doctor applications and manual verification in American English.

== Complete workflow ==
* Any logged-in user may begin a doctor application.
* Email and Google Account login remain available through File 02.
* Required professional profile fields and a 100 percent completion gate.
* Identity, qualification, and license evidence encrypted with AES-256-GCM before storage.
* Credential files are not placed in the Media Library and direct URLs contain ciphertext only.
* Authorized manual review, evidence download, review notes, audit history, email updates, more-information requests, rejection, verification, and suspension.
* Verified role integration with Files 03, 07, and 08.
* Resubmission and document replacement.
* Privacy export, credential deletion, privacy-policy text, noindex, noarchive, and no-cache application page.

== Requirements ==
Files 02, 03, and 07 should be active. File 08 is recommended for clinic appointments.

== Important verification statement ==
This plugin completes the platform workflow. It does not automatically connect to every government licensing registry worldwide. The Founder or an authorized administrator must independently evaluate submitted evidence and applicable local requirements before approval.

== Installation ==
1. Keep Files 02, 03, and 07 active.
2. Upload and activate this ZIP.
3. Open Doctor Applications in WordPress Admin.
4. Test application, encrypted download, more-information, rejection, approval, and public-directory visibility with test accounts.
